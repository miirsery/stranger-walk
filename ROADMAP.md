# План улучшений Stranger Walk

Порядок этапов — по отдаче для игрока: сначала то, что мешает играть сейчас,
затем глубина и контент, затем внешний вид, платформы и сервер.
Отмечено `[x]` — сделано, `[ ]` — впереди.

## Этап 1. Играбельность и честный баланс

Цель: то, что уже есть, должно быть удобным и проходимым на любом устройстве.

- [x] **Баланс по цифрам.** Симулятор боёв «ИИ против ИИ» (`core/battle/simulate.ts`) и тест
      `content/balance.test.ts` с коридорами побед для каждого босса. Любая правка карт или колод,
      ломающая баланс, теперь роняет тесты.
- [x] **ИИ противника умнее.** Добивает героя, когда урона хватает; не тратит заклинания впустую
      (лечение при полном здоровье, урон по пустому столу).
- [x] **Мобильная вёрстка.** Масштаб мира для портретных экранов, рука в бою одной прокручиваемой
      строкой, поле мини-игры на память помещается в ширину телефона.
- [x] **Обучение в первом бою.** Четыре подсказки, которые сменяются по действиям игрока; можно пропустить.
- [x] **Журнал квестов и коллекция** (клавиша `J`): все квесты с описаниями и картотека игры
      по мирам, ненайденные карты закрыты.
- [x] **Аналоговый тач-джойстик** вместо крестовины; поддержка геймпада (стик, крестовина, кнопка A).
- [ ] **Проверка на реальных устройствах** (iOS Safari, Android Chrome, геймпад): звук, жесты, безопасные зоны.

## Этап 2. Глубина карточной игры

Цель: бой должен давать решения, а не только «сыграй самое дорогое».

- [ ] **Заклинания с выбором цели**: урон или лечение по конкретному существу.
- [ ] **Новые ключевые слова**: «предсмертный хрип», «яд», «щит», аура.
- [ ] **Анимации боя**: выпад при атаке, вылет урона, смерть существа, розыгрыш карты.
- [ ] **Уникальная механика у каждого босса** (например, сила героя раз в ход).
- [ ] **Выбор награды из трёх карт** после боя и мини-игр — чтобы колоды у игроков различались.
- [ ] **Муллиган** стартовой руки.
- [ ] **Уровни сложности ИИ**: просчёт на ход вперёд для поздних боссов.

## Этап 3. Контент и мир

Цель: полноценная сюжетная линия на 1–2 часа.

- [ ] **Новые уровни** в каждом сеттинге, побочные квесты, секреты на картах.
- [ ] **Третья и четвёртая мини-игры**: ритм (под чиптюн-музыку) и рыбалка на подлодке.
- [ ] **Торговец картами** и внутриигровая валюта за мини-игры.
- [ ] **Сюжетные сцены** между мирами и финал.
- [ ] **Живой мир**: NPC ходят и поворачиваются к игроку, сундуки, двери, таблички.
- [ ] **Редактор Tiled** вместо ASCII-карт, когда уровней станет больше десяти.

## Этап 4. Графика и звук

Цель: заменить заглушки авторским стилем.

- [ ] **Спрайты и тайлсеты** вместо процедурных текстур (правки только в `render/textures.ts`).
- [ ] **Иллюстрации карт** вместо буквы на цветном фоне.
- [ ] **Анимированные тайлы** (вода, факелы, звёзды), переходы между уровнями, частицы.
- [ ] **Музыка**: по 1–2 полноценных трека на сеттинг, шумовой канал для ударных, звуки шагов.

## Этап 5. Техническое качество

- [x] **CI**: lint, тесты и сборка на каждый пуш, автодеплой на GitHub Pages.
- [ ] **E2E-тесты** (Playwright): сквозное прохождение в настоящем браузере.
- [ ] **PWA**: установка на домашний экран и игра офлайн.
- [ ] **Размер сборки**: сейчас Phaser весит ~360 КБ gzip — собрать урезанную версию без неиспользуемых модулей.
- [ ] **Обработка ошибок**: экран «что-то пошло не так» с возможностью продолжить с сохранения.
- [ ] **i18n**: вынести тексты из контента в словари, добавить английский.
- [ ] **Переход на TypeScript 7**, когда его поддержит typescript-eslint.

## Этап 6. Сервер

Цель: прогресс не привязан к одному браузеру.

- [ ] **Учётные записи** в Rust-бэкенде (регистрация, вход, сессии).
- [ ] **Облачные сохранения**: API + реализация `SaveStorage` поверх него, разрешение конфликтов.
- [ ] **Таблица рекордов** мини-игр.
- [ ] **Развёртывание бэкенда** и HTTPS.

## Этап 7. Платформы

- [ ] **Capacitor**: сборки для iOS и Android.
- [ ] **Tauri**: сборки для macOS и Windows.
- [ ] **Нативные мелочи**: вибрация, полноэкранный режим, сохранения в файловую систему.
