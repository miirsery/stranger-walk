# План улучшений Stranger Walk

Старый план устарел: всё, что в нём было важно, либо сделано (см. историю коммитов),
либо потеряло смысл. Ниже — новый список направлений, с нуля.

Порядок — по отдаче для игрока: сначала глубина и повторная играбельность того, что
уже есть, затем новый контент, затем полировка UX, техника, сервер и платформы.

## Этап 1. Глубина и повторная играбельность

Цель: игру хочется пройти больше одного раза.

- [x] **New Game+**: после эпилога — повторный проход с усиленными боссами (+25% здоровья
      за цикл) и сохранённой коллекцией карт — доступ к наградам прежних сундуков не теряется.
      Квесты, боссы, мини-игры, сундуки и двери сбрасываются к началу игры; счётчик цикла — в
      сохранении и в журнале.
- [x] **Достижения**: вкладка в журнале (клавиша `J`) — «без единого поражения» (нужна
      победа над финальным боссом без поражений/сдач), «победитель всех боссов», «знаток
      мини-игр», «коллекционер» по одному на каждый сеттинг с картами. Раз засчитанные
      остаются засчитанными навсегда, даже после New Game+.
- [x] **Бестиарий**: вкладка в журнале — карточка каждого босса с лором, открывается после
      первой же встречи (бой начат, победа не обязательна), статус «повержен» отдельно.
- [x] **Альтернативная стартовая колода**: экран «Выбери колоду» перед новой игрой — три
      варианта из карт лугов («Разведчик» — ровная, «Рой» — агро, «Бастион» — контроль/лечение).
- [x] **Элитные враги на карте мира**: «Страж каземата» в «Нижнем каземате» — необязательный
      сильный бой вне сюжета и квестов, уникальная награда — легендарная карта «Страж каземата»
      (защитник + яд), которую больше нигде не получить.
- [x] **Второй игровой ресурс в бою — ярость**: растёт на 1 с каждой атакой существа (у обеих
      сторон), при заполнении шкалы (6) доступен «Взрыв ярости» — урон герою врага, не тратит
      ману и не привязан к ходу розыгрыша карт. ИИ тоже использует её. Баланс пересчитан и
      уложен в прежние коридоры побед.
- [x] **Экипировка/артефакты вне боя** (доп. пункт сверх исходного плана): три артефакта
      («Амулет стойкости» +4 здоровья, «Перчатка мага» сила героя на 1 ману дешевле, «Пояс
      ярости» удваивает прирост ярости за атаку) — продаются у торговки Лины за монеты,
      экипирован максимум один за раз (вкладка в «Колоде»), эффект действует весь следующий бой.

## Этап 2. Новый контент

Цель: больше мира, веток и причин возвращаться в уже пройденные уровни.

- [x] **Пятый сеттинг — «Пещеры»**: скрытый портал в земле на Тихих лугах (всегда открыт,
      без квестов), своя палитра тайлов и музыка. Необязательный босс «Кристальный голем»
      (легендарная карта-эксклюзив «Сердце голема» в награду), эксклюзивная мини-игра на
      память «Эхо пещер» и сундук — 7 новых карт сеттинга.
- [x] **Пятый тип мини-игры**: «Пятнашки» — классическая головоломка на перемещение плиток
      (3×3, ограничение по числу ходов). Отшельница Зоя в «Старом лесу» предлагает её
      безусловно, вне квестов; награда — карта «Жнец» и выбор одной из трёх.
- [x] **Ветвящиеся побочные квесты**: в диалоге NPC появился выбор (`NpcScript.choices`) —
      свои реплики и свои эффекты на вариант, плюс свободные флаги истории (`setFlag`/
      условие `flag`) для реакции при повторном визите. Квест-пример — «Лисица в капкане»
      на лугах: отпустить (карта «Пир урожая») или забрать шкуру (карта «Пугало»), и NPC
      потом помнит выбор.
- [x] **Репутация NPC**: число, растущее и падающее от мелких поступков (условие
      `reputation`, эффект `changeReputation`). Выбор у лисицы в капкане и у бродяги
      Кузьмы на лугах копятся вместе и меняют, что говорит и почём продаёт торговка
      Лина (скидка от +3, наценка от −3); видно в журнале.
- [x] **Секретная «истинная» концовка**: пять легендарных «осколков», по одному
      гарантированному (`WorldObjectDef.chest.guaranteed`) в тайнике каждого сеттинга —
      луга, подлодка, замок, станция, пещеры. Собравший все до победы над Капитаном
      Пустоты получает сцену сверх обычного эпилога, а не вместо него.

## Этап 3. UX и доступность

Цель: убрать мелкое раздражение, которое не видно на демо, но мешает при реальной игре.

- [x] **Скорость текста диалогов**: настройка «Медленно / Обычно / Быстро / Мгновенно»
      (страница «Настройки»). Реплика печатается посимвольно; нажатие (клавиатура, клик,
      геймпад — один и тот же путь) сперва показывает её целиком, затем продвигает диалог.
- [x] **Несколько слотов сохранения**: 3 независимых слота (экран «Сохранения» в меню) —
      у каждого своя игра, превью (мир, число карт, дата) и удаление с подтверждением.
      Старое одиночное сохранение переносится в слот 1 автоматически. Явный индикатор
      «Сохранено» коротко показывается после каждой записи прогресса.
- [x] **Режим высокой контрастности / для дальтоников**: настройка «Контраст» переключает
      всю палитру на вариант с максимальной яркостной разницей и колорблинд-безопасными
      оттенками (без путаницы красный/зелёный). Заодно убраны места, где смысл нёс только
      цвет: атака/здоровье на картах получили значки ⚔/♥, редкость — ромбики-пипсы.
- [x] **Переназначение управления**: страница «Управление» — своя клавиша для движения
      (4 направления), действия, паузы, колоды и журнала, с проверкой занятых клавиш;
      своя кнопка геймпада для действия. Стрелки и Space/Enter остаются запасным путём.
- [x] **Подсказка «что нового»** при патче: короткий экран с изменениями показывается
      в главном меню при первом запуске после обновления версии (`settings.lastSeenVersion`
      против `changelog.ts`). Новым игрокам и уже отслеженным версиям экран не показывается.

## Этап 4. Техническое качество

- [ ] **i18n**: вынести тексты контента в словари, добавить английскую локализацию.
      _Отложено: в контенте сотни строк (карты/квесты/диалоги/лор боссов) плюс весь UI —
      полный перевод не укладывается в один присест; решили пропустить пункт пока что._
- [x] **Код-сплиттинг по сеттингам**: арт тайлов и персонажей грузится только для текущего
      уровня при входе в игру (`queueArt` в `WorldScene.preload()`); остальные сеттинги
      догружаются в фоне из `create()`, не блокируя первый кадр.
- [x] **Сбор ошибок в проде**: каждое падение (Vue, `window.onerror`, unhandled promise)
      сохраняется в локальный журнал (виден и копируется из отладочной панели) вместе с
      контекстом — уровень, режим, цикл NG+. Если задать `VITE_ERROR_REPORT_URL` при сборке,
      отчёт дополнительно уходит туда POST'ом — своему коллектору или Sentry-совместимому
      приёмнику; без переменной — только локальный журнал, никуда ничего не шлётся.
- [x] **E2E на бой и мини-игры**: новые сценарии в `e2e/game.spec.ts` доводят реальный UI
      до карточного боя (диалог → мулиган → ход → победа → награда → мир) и до мини-игры
      («Сбор урожая»: диалог → интро → победа → награда); правила самого движка уже
      дотошно проверены юнит-тестами, e2e ловит регрессии в переходах между экранами.
      Заодно починил старые сценарии под экран выбора слота сохранения, который не пропускал.
- [x] **Профилирование на слабых устройствах**: своего старого Android-телефона нет под
      рукой, поэтому вместо замера — инструмент для него. В `?debug=1` добавлен живой
      счётчик «FPS · Память» (обновляется дважды в секунду; память — только в Chrome,
      через `performance.memory`). Чек-лист, что пройти и на что смотреть — `PERF_TESTING.md`.
- [ ] **Переход на TypeScript 7**, когда его поддержит `vue-tsc`/Volar.
      _Отложено (проверено 2026-11-27): стабильный TS 7.0 убрал программный API, на который
      опирается vue-tsc/Volar — поддержка возвращается только в TS 7.1 (пока beta), отзывы
      о совместимости противоречивы. Ждём стабильный 7.1. Сейчас в проекте TypeScript 6.0.3._

## Этап 5. Сервер и социальные фичи

Цель: прогресс и соревнование не привязаны к одному браузеру и одному игроку.

- [ ] **Облачные сохранения**: API + `SaveStorage` поверх уже готовой авторизации,
      разрешение конфликтов при игре с разных устройств.
- [ ] **Таблица рекордов мини-игр**: лучший результат по каждой из четырёх, с фильтром
      «друзья»/«все».
- [ ] **Вызов дня**: общий сид для всех игроков на сутки (например, фиксированный
      порядок карт в сундуках) с отдельным лидербордом.
- [ ] **Шаринг результата**: ссылка-снапшот финальной колоды или боя с боссом для показа
      другим без раскрытия сохранения целиком.

## Этап 6. Публикация и платформы

- [ ] **Capacitor**: сборки для iOS и Android.
- [ ] **Tauri**: сборки для macOS и Windows.
- [ ] **Витрина для демо**: страница/сборка под Steam или аналог, с трейлером и скриншотами.
- [ ] **Нативные мелочи**: вибрация при ударе в бою, полноэкранный режим, сохранение
