# План улучшений Stranger Walk

Порядок этапов — по отдаче для игрока: сначала то, что мешает играть сейчас,
затем глубина и контент, затем внешний вид, платформы и сервер.
Отмечено `[x]` — сделано, `[ ]` — впереди.

## Замечания после игры

Проблемы, найденные при реальной игре. Идут раньше всех этапов ниже.

- [x] **Экран загрузки вместо пустого фиолетового экрана.** Пиксельный лоадер (шагающий Странник,
      полоса прогресса, случайная подсказка) держится до первого кадра мира. Движок и экран игры
      скачиваются заранее, пока игрок в главном меню.
- [x] **Выход из мини-игры и её перезапуск.** Мини-игра начинается с экрана правил («Начать» / «Выйти»),
      для уже пройденной — с пометкой, что награда получена. Во время игры есть кнопки «Заново» и «Выйти»,
      после — экран итога. Награды и прогресс квеста при выходе не теряются.
- [x] **Читаемость на больших мониторах (2K/4K).** Интерфейс масштабируется от размера окна
      (×1,5 на 1080p, ×2 на 1440p, ×3 на 4K); в настройках есть ручной выбор «Размер интерфейса».
- [x] **Мобильная вёрстка без пересечений.** Проверены 360×640, 375×812 и альбомная 812×375:
      компактная панель квестов, уведомления отдельной строкой, подсказка над джойстиком,
      джойстик скрыт в диалогах, бой помещается на экран, отдельная раскладка боя для альбомной ориентации.
- [x] **Режим отладки.** Кнопка DBG в dev-сборке и на сайте по параметру `?debug=1`: выиграть мини-игру
      или бой, завершить квесты, выдать все карты, открыть порталы, телепорт на любой уровень.
- [x] **Подсказки по картам прямо в бою.** Непонятно было, что делают заклинания и ключевые слова
      («Рывок», «Защитник» и т.п.) на картах в руке и на столе. Значок «?» на каждой карте в бою —
      по наведению (десктоп) или по тапу (телефон) — показывает полный текст карты и расшифровку
      её ключевых слов. Не задевает клики по самой карте (разыграть/атаковать/заменить в стартовой руке).
- [ ] **Проверить всё это на реальных устройствах**: 2K-монитор и телефон (до сих пор — только эмуляция).

## Этап 1. Играбельность и честный баланс

Цель: то, что уже есть, должно быть удобным и проходимым на любом устройстве.

- [x] **Баланс по цифрам.** Симулятор боёв «ИИ против ИИ» (`core/battle/simulate.ts`) и тест
      `content/balance.test.ts` с коридорами побед для каждого босса. Любая правка карт или колод,
      ломающая баланс, теперь роняет тесты.
- [x] **ИИ противника умнее.** Добивает героя, когда урона хватает; не тратит заклинания впустую
      (лечение при полном здоровье, урон по пустому столу).
- [x] **Мобильная вёрстка.** Масштаб мира для портретных экранов, рука в бою одной прокручиваемой
      строкой, поле мини-игры на память помещается в ширину телефона.
- [x] **Обучение в первом бою.** Четыре подсказки, которые сменяются по действиям игрока; можно пропустить.
- [x] **Журнал квестов и коллекция** (клавиша `J`): все квесты с описаниями и картотека игры
      по мирам, ненайденные карты закрыты.
- [x] **Аналоговый тач-джойстик** вместо крестовины; поддержка геймпада (стик, крестовина, кнопка A).
- [ ] **Проверка на реальных устройствах** (iOS Safari, Android Chrome, геймпад): звук, жесты, безопасные зоны.

## Этап 2. Глубина карточной игры

Цель: бой должен давать решения, а не только «сыграй самое дорогое».

- [x] **Заклинания с выбором цели**: урон по существу или герою, усиление своего существа; ИИ тоже выбирает цели.
- [x] **Эффекты гибели** («Морская мина», «Призрак»).
- [x] **Новые ключевые слова**: «яд» (убивает любое раненое существо) и «щит» (гасит первый удар); четыре новые карты лежат в сундуках.
- [x] **Аура**: «Знаменосец» даёт остальным своим существам +1 к атаке, пока стоит на столе (лежит в сундуке замка).
- [x] **Анимации боя**: выпад при атаке, тряска цели, появление и гибель существ.
- [x] **Вылет цифр урона и лечения** над существами и героями.
- [x] **Анимация полёта заклинания**: светящийся снаряд летит от героя-заклинателя к цели (существу или герою).
- [x] **Силы героев**: у Странника и у каждого босса своя способность раз в ход за ману.
- [x] **Выбор награды из трёх карт** — в сундуках.
- [x] **Выбор награды после боёв и мини-игр**: за первую победу — ещё одна карта из трёх (`rewardChoices` в контенте).
- [x] **Замена стартовой руки** перед первым ходом.
- [x] **Уровни сложности ИИ**: «жадный» и «умный» (`ai` у босса). Умный перебирает варианты хода на копии боя и оценивает итог; Капитан Пустоты играет им.

## Этап 3. Контент и мир

Цель: полноценная сюжетная линия на 1–2 часа.

- [ ] **Новые уровни** в каждом сеттинге. Пока один: «Старый лес» — необязательная боковая
      карта на Тихих лугах (новый портал в западной стене), с NPC-лесником и побочным квестом
      «Лесная тропа» (награда — «Гадюка»). Остальные сеттинги — впереди.
- [x] **Побочный квест**: «Дикий рой» на Тихих лугах — пасечник Тихон просит прогнать рой пчёл, разблокируется
      после «Первых шагов», наградой идёт новая карта «Дикий рой» (рывок).
- [x] **Секреты на картах**: тайник за рычагом и дверью на «Наутилусе-8» (сундук с глубинными картами), в замке
      Хранителя (сундук с «Оруженосцем» — ранее картой только для Хранителя) и на станции «Горизонт» (аварийный
      отсек со звёздными картами). По образцу тайника на Тихих лугах — теперь есть в каждом сеттинге.
- [ ] **Третья и четвёртая мини-игры**: ритм (под чиптюн-музыку) и рыбалка на подлодке.
- [x] **Торговец картами** и внутриигровая валюта за мини-игры: победа в любой мини-игре (не только первая) приносит монеты; на них у торговца на Тихих лугах можно купить карты из его лавки, пока хватает монет.
- [x] **Сюжетные сцены между мирами**: глава из журнала (`story.ts`) с привязкой к уровню (`levelId`) показывается заставкой при первом входе в него — на старте новой игры и при переходе через портал; повтор не предусмотрен, отметка хранится в сохранении (`seenChapters`).
- [x] **Финал**: после победы над Капитаном Пустоты (последний босс, квест `beyond`) — отдельный экран-эпилог вместо реплики «Продолжение следует», с текстом о возвращённой колоде. Мир не блокируется: экран можно закрыть и продолжить игру.
- [x] **Живой мир, первая часть**: сундуки с выбором карты и таблички в каждом мире, NPC поворачиваются к игроку.
- [x] **Двери и рычаги**: дверь непроходима, пока её рычаг не потянут (насовсем); состояние сохраняется отдельно для каждого уровня. Пример — тайник на Тихих лугах.
- [x] **NPC ходят по маршрутам**: точки маршрута обходятся по очереди туда-обратно; у игрока рядом NPC по-прежнему поворачивается к нему. Пример — механик на «Наутилусе-8».
- [ ] **Редактор Tiled** вместо ASCII-карт, когда уровней станет больше десяти.

## Этап 4. Графика и звук

Цель: заменить заглушки авторским стилем.

- [x] **Спрайты и тайлсеты** вместо процедурных текстур. AI-арт (9 персонажей, 21 тайл на 4 сеттинга) нарезан
      скриптом из сгенерированных листов в `public/assets/{characters,tiles}`. `textures.ts` рисует его на
      холст вместо прямоугольников, когда для id/тайла есть файл, — иначе прежняя процедурная заглушка.
      Второго кадра анимации у тайлов нет, оба кадра показывают один и тот же рисунок.
- [x] **Иллюстрации карт** вместо буквы на цветном фоне. 33 из 36 карт — в `public/assets/cards`;
      `CardFace.vue` показывает картинку, если она есть, иначе — прежний фолбэк (буква на цвете сеттинга).
      Без иллюстрации пока остались Паладин, Знаменосец и Силовой барьер.
- [x] **Анимированные тайлы**: вода, звёзды, факелы, иллюминаторы и люки.
- [x] **Частицы и эффекты**: следы пыли под ногами на ходу, искры у факелов, брызги над водой.
      Собственная лёгкая система поверх обычных `Image` (не штатный `Phaser.ParticleEmitter` — в
      4.2.1 он не рисуется при скролле камеры, проверено на тестовых частицах; баг движка, не конфига).
- [x] **Шумовой канал для ударных и звук шага**: общий буфер белого шума, форма (бочка/малый/хай-хэт)
      задаётся фильтром; паттерн ударных — отдельная партия трека, как `lead`/`bass`. Шаги игрока озвучены.
- [x] **Второй трек на сеттинг**: `SettingDef.musicAlt` — у каждого из 4 сеттингов свой второй вариант
      (`fields2`, `submarine2`, `castle2`, `space2`); при входе в мир `audioDirector` выбирает один из
      двух наугад и держит его, пока сеттинг не сменится (пауза/диалог/бой не пересчитывают выбор).

## Этап 5. Техническое качество

- [x] **CI**: lint, тесты и сборка на каждый пуш, автодеплой на GitHub Pages.
- [x] **E2E-тесты** (Playwright): сквозное прохождение в настоящем браузере — главное меню, старт игры и вступительная сцена,
      движение персонажа, журнал/колода, пауза; запускаются в CI перед сборкой.
- [x] **PWA**: установка на домашний экран и игра офлайн. `vite-plugin-pwa` генерирует манифест и
      service worker (кэширует весь собранный бандл, включая лениво загружаемые движок и экран игры);
      иконки — тот же пиксельный спрайт Странника, что и в игре. Проверено: отключение сервера после
      установки не мешает дойти до мира.
- [ ] **Размер сборки**: сейчас Phaser весит ~360 КБ gzip. Проверено: npm-пакет публикует только один готовый
      ESM-бандл (`exports` в package.json закрывает доступ к исходникам), и даже принудительный tree-shake
      на уровне Rollup не уменьшает его ни на байт — класс не выбрасывается, пока не исчезнет из публичного
      неймспейса `Phaser.*`, который сам пакет и собирает. Урезанная сборка возможна только из исходников
      Phaser с ручным импортом нужных классов в обход неймспейса — хрупко при обновлении версии; не делали.
      Движок и так грузится лениво (во время меню) и теперь кэшируется офлайн (см. PWA выше).
- [x] **Обработка ошибок**: при любой непойманной ошибке (Vue, глобальная, промис) — полноэкранный «что-то пошло не так» вместо сломанного интерфейса, с кнопками «Продолжить» (перезагрузка, игрок возвращается в сохранённую точку) и «В главное меню», и подробностями ошибки для отладки.
- [ ] **i18n**: вынести тексты из контента в словари, добавить английский.
- [ ] **Переход на TypeScript 7**, когда его поддержит `vue-tsc`/Volar.

## Этап 6. Сервер

Цель: прогресс не привязан к одному браузеру.

- [x] **Учётные записи** в Rust-бэкенде: регистрация, вход, сессии (`/api/v1/auth/*`). Пароли —
      argon2, токен сессии живёт в HTTP-only cookie (`SameSite=Lax`, 30 дней), в базе — только его
      SHA-256. Регистрация и выдача сессии — одной транзакцией. Проверено живьём через `docker compose`
      (регистрация, вход, `/me`, выход, повтор имени, неверный пароль, валидация полей). Фронтенд к
      этим маршрутам ещё не обращается — экран входа появится вместе с облачными сохранениями ниже.
- [ ] **Облачные сохранения**: API + реализация `SaveStorage` поверх него, разрешение конфликтов.
- [ ] **Таблица рекордов** мини-игр.
- [ ] **Развёртывание бэкенда** и HTTPS.
