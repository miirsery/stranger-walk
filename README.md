# Stranger Walk

Пиксельная браузерная RPG с видом сверху: ходи по мирам, выполняй квесты, играй в мини-игры,
собирай карты и побеждай боссов в карточном бою.

Сейчас это **каркас и MVP**: четыре локации (луга → подлодка → замок → орбитальная станция),
четыре квеста, две мини-игры («Сбор урожая» и «Опись груза» на память), редактор колоды
(клавиша `C`) и карточные бои с двумя боссами: существа, заклинания и эффекты «при выходе». Прогресс автоматически сохраняется в браузере (localStorage).

## Запуск

Нужны Node.js ≥ 22.12 и (для бэкенда) Docker.

```bash
npm install
npm run dev          # игра: http://localhost:5173
```

```bash
docker compose up --build   # Rust-бэкенд + PostgreSQL: http://localhost:8080/api/v1/health
```

Бэкенд игре пока не нужен — он заложен под будущую синхронизацию сохранений между устройствами.

Режим отладки (кнопка DBG: выиграть мини-игру или бой, выдать карты, телепорт) включён в `npm run dev`,
а на опубликованном сайте — по адресу с `?debug=1`.

| Команда             | Что делает                                   |
| ------------------- | -------------------------------------------- |
| `npm run dev`       | dev-сервер Vite с горячей перезагрузкой      |
| `npm run build`     | проверка типов + production-сборка в `dist/` |
| `npm run test`      | тесты игровой логики (Vitest)                |
| `npm run lint`      | ESLint (`lint:fix` — с автоисправлением)     |
| `npm run typecheck` | только проверка типов                        |

## Архитектура

Четыре слоя с односторонними зависимостями: **ядро ничего не знает о Vue, Phaser и DOM**.
Это проверяется дважды — `tsconfig.core.json` собирает ядро без библиотеки `DOM`,
а ESLint запрещает в нём импорты слоёв представления.

```
src/
├── core/            Игровая логика. Чистый TypeScript, переносим на любую платформу.
│   ├── content/     Типы модели данных, реестр и валидатор контента
│   ├── world/       Тайловая карта, движение, столкновения, порталы
│   ├── quests/      Журнал квестов
│   ├── cards/       Инвентарь карт и колода
│   ├── battle/      Движок карточного боя + ИИ противника
│   ├── minigames/   Логика мини-игр (контракт Minigame + CatchGame)
│   ├── session/     GameSession — связывает всё, машина сцен, события
│   └── util/        ГПСЧ с seed, шина событий
├── content/         ДАННЫЕ игры: сеттинги, уровни, NPC, квесты, карты, боссы, музыка, сюжет
├── render/          Phaser: сцены мира и мини-игры, камера, процедурные текстуры
├── input/           Клавиатура + сенсорные кнопки → единый MoveInput
├── audio/           Чиптюн-синтезатор на Web Audio (музыка и эффекты из данных)
├── platform/        Хранилище сохранений (сейчас localStorage, интерфейс SaveStorage)
└── ui/              Vue: меню, настройки, страницы, HUD, диалоги, экран карточного боя
backend/             Rust-сервис (axum + sqlx) и SQL-миграции
docker-compose.yml   backend + PostgreSQL
```

Как это работает в рантайме:

1. `GameSession` (ядро) хранит состояние и текущий режим: `world` · `dialog` · `minigame` · `battle`.
2. Phaser каждый кадр вызывает `session.update(dt, input)` и рисует результат.
3. Vue подписан на `session.events` и показывает HUD, диалоги и карточный бой поверх канваса.
4. Аудио подписано на те же события: выбирает трек под сцену и играет эффекты.

## Как добавлять контент (без правок движка)

Всё в `src/content/`, типы — в `src/core/content/types.ts`:

- **Карта** — строка в `cards.ts`: существо (`unit`) или заклинание (`spell`) с эффектом из набора `CardEffect`.
- **Уровень** — ASCII-карта в `levels.ts`: символы — тайлы сеттинга, плюс NPC и порталы.
- **Сеттинг** (поля, подлодка, замок, космос…) — набор тайлов и трек в `settings.ts`.
- **NPC и диалоги** — `npcs.ts`: сценарии с условиями (`when`) и эффектами (`startQuest`, `startMinigame`, `startBattle`, `grantCards`).
- **Квест** — `quests.ts`: цели (`talkTo`, `winMinigame`, `enterLevel`, `defeatBoss`) и карты в награду.
- **Босс** — `bosses.ts`: здоровье, колода, награда.
- **Музыка** — `music.ts`: ноты строкой.

Тест `src/content/content.test.ts` проверяет ссылочную целостность: опечатка в id или
«кривая» карта уровня ловится в `npm run test`, а не в игре.

Новый **тип** мини-игры или механики карт — это уже код: класс в `core/minigames` + сцена в `render/scenes`.

**Почему TypeScript 6.0.3, а не 7.0.2.** Последний стабильный TypeScript — 7.0, но
`typescript-eslint` 8.72 поддерживает только `typescript <6.1`. Чтобы линтер работал,
взята последняя версия ветки 6.0. Перейти на 7 можно, когда typescript-eslint добавит поддержку.

**Почему Phaser.** Из коробки даёт всё нужное топ-даун RPG: тайловые карты, камеру со сглаженным
следованием, сцены, `pixelArt`-режим. PixiJS — только рендерер (карты, камеру и сцены пришлось бы писать),
«голый» canvas — ещё больше ручной работы. Phaser работает в WebView, поэтому перенос на iOS/Android
(Capacitor) и macOS/Windows (Tauri/Electron) — это упаковка той же сборки.

**Почему карточный бой на Vue, а не в Phaser.** Карты — это текст, кнопки и состояния наведения;
DOM даёт это вместе с доступностью и адаптивностью. Движок боя при этом в ядре и от UI не зависит.

**Почему звук синтезируется.** 8-битная музыка — это квадратные и треугольные волны; Web Audio
генерирует их из нот в `content/music.ts`. Нет аудиофайлов — нет вопросов с лицензиями и весом сборки.

**Бэкенд.** axum — самый распространённый веб-фреймворк на tokio, от той же команды. sqlx вместо ORM:
обычный SQL, асинхронность, встроенные миграции (`migrations/*.sql` применяются при старте).
Сейчас есть только `GET /api/v1/health` и таблица `players` как точка опоры для сохранений.

## Пиксельная графика

- Phaser запущен с `pixelArt: true` и `roundPixels: true` (сглаживание выключено).
- Масштаб только целочисленный: `computeViewport` в `render/createGame.ts` выбирает zoom ×1, ×2, ×3…
  от базового разрешения 320×180 и подгоняет размер поля под окно.
- Спрайтов пока нет: тайлы и персонажи рисуются процедурно из цветов в контенте (`render/textures.ts`).

## Что дальше

Полный план по этапам с отметками о сделанном — в [ROADMAP.md](ROADMAP.md). Коротко:

1. **Графика**: заменить процедурные текстуры атласами спрайтов (правки только в `render/textures.ts`), анимации.
2. **Сохранения на сервере**: API в бэкенде (игроки, прогресс) и реализация `SaveStorage` поверх него —
   сериализация `GameSession` и формат `SaveData` уже есть.
3. **Карточная игра**: эффекты с выбором цели, анимации атак, баланс.
4. **Контент**: новые уровни и боссы, полная сюжетная линия.
5. **Мини-игры**: новые типы (ритм, рыбалка) через контракт `Minigame`.
6. **Карты уровней**: при росте мира перейти с ASCII на редактор Tiled (Phaser читает его формат).
7. **Управление**: аналоговый тач-джойстик, геймпад (добавляются в `InputHub`).
8. **Платформы**: Capacitor (iOS/Android) и Tauri (macOS/Windows) поверх той же сборки.
9. **Инфраструктура**: CI (lint + test + build + cargo check), e2e-тесты, i18n.
